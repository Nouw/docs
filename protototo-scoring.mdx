title: "Protototo scoring: how prediction points work"
description: "Learn how Protototo awards points for each match: one per correct set winner, one for the exact set score, and one for the correct match winner."
---

Protototo awards points per match by comparing your prediction to the final result. Use this page to understand how your standings total is calculated.

## Scoring rules

For each match, you earn:

| Rule | Points |
| --- | --- |
| Correct set winner | 1 point per set |
| Exact set score (for example, 3-1) | 1 extra point |
| Correct match winner | 1 point |

Protototo compares set winners by position. Your prediction for set 1 is checked against the result of set 1, and so on.

You don't receive points for participating. A match where you predicted nothing correctly scores 0 points.

## Drawn results

In the four-sets format, a match can end 2-2. A drawn result has no winner, so nobody earns the match winner point. You can still earn set points and the exact score point for a 2-2 prediction.

## Example

The result is 3-1 with sets won, won, lost, won. You predicted won, won, won, lost.

- **Set winners:** sets 1 and 2 are correct, so you earn 2 points.
- **Exact score:** you predicted 3-1 and the result is 3-1, so you earn 1 point.
- **Match winner:** you predicted the correct winner, so you earn 1 point.

Your total for this match is 4 points.

<Note>
  Protototo calculates points when you view the standings. Rounds played before these rules took effect are re-scored with the current rules.
</Note>
